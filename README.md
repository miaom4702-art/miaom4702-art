## 🚀 核心项目 · 重要贡献

### 🎭 DesktopAI · 月见八千代 &nbsp;<sub>Live2D 桌面 AI 伴侣 · Desktop Live2D AI Companion</sub>

> 一款运行于 Windows 桌面的 Live2D 虚拟角色 AI 伴侣，内置角色「月见八千代」（Tsukimi Yachiyo），将大语言模型、语音识别、语音合成、长期记忆与情感表达深度整合，与用户实时对话。

- 🖥️ **实时 Live2D 角色**：无边框透明悬浮窗常驻桌面，按情绪切换表情，并用拼音驱动口型同步
- 🗣️ **能听会说**：Vosk 离线中文语音输入（支持语音活动打断）+ edge-tts / DashScope CosyVoice 语音合成
- 🎙️ **声音克隆**：可克隆任意音色，并支持日语朗读模式
- 🧠 **长期记忆**：对话历史与用户记忆本地持久化，重启后仍记得你
- 🎮 **VTube Studio 联动**：通过 WebSocket 注入情绪与参数
- ✅ 附 **pytest 单元测试**

<sub>**技术栈**</sub> &nbsp; `Python` · `Live2D` · `Qwen / DashScope` · `Vosk` · `edge-tts` · `Flask`

---

### 🛡️ zzz-chat &nbsp;<sub>绝区零 AI 角色对话</sub>

> 《绝区零》风格的角色对话网页，重点是一次**安全改造**——修复前端泄露 API Key 的严重问题。

- 🔐 将原本**硬编码在前端 HTML 的 DashScope API Key** 迁移至后端代理，浏览器请求中不再含任何密钥
- 📦 后端**零第三方依赖**（仅 Python 标准库），同时充当静态文件服务器
- 💬 角色人格化对话 + 服务端对话记忆
- 🖼️ 附带素材随机展示页与拼贴生成脚本

<sub>**技术栈**</sub> &nbsp; `Python` · `HTML` · `JavaScript`

---

### 🎨 webui &nbsp;<sub>画师作品集网站</sub>

> 纯静态、数据驱动的画师作品展示网站，零依赖、可直接部署到任意静态托管服务。

- 🗂️ 目录页 + 详情页，数据集中于 `data/artists.js`，改数据不改结构
- 📱 响应式布局（平板 / 手机适配）、图片懒加载、滚动淡入动画
- 🚀 一键部署到 GitHub Pages / Netlify / Vercel

<sub>**技术栈**</sub> &nbsp; `HTML` · `CSS` · `JavaScript`
